# Lossless active-mask operator transport

`packed_operator_response.GpuPackedOperatorBoxResponse` is a separate opt-in owner derived from the qualified shared-operator response. It uses the original registry/detection owners and has no warm-start plumbing or seeds. Existing owners and defaults remain unchanged.

Only normal-mask table transport changes. The table remains sixteen embedded 4x4 pseudoinverse blocks in its logical representation; arithmetic still reads the original 256-word local/shared layout. It is not a 16x16 matrix or the nonlinear tangent Jacobian. Original mask order, invalid flags, minimum-norm/tie choices, pivots, reductions, zero products, caps, initialization, barriers and early-inner policy are retained. No stored-bit symmetry is assumed.

For n=0..4, compact payload is 0,1,6,24,80 Float64 words: entries whose row and column are selected by a used mask and lie within n. Their original bits are copied in mask/row/column order. Encoder checks every omitted position by UInt64 bits. If any omitted word differs from positive zero, including negative zero, infinity or a NaN payload, it uses exact dense fallback rather than discarding that word. Both modes reconstruct all 256 words, including invalid and inactive-mask data. Nonfinite input handling and solver rejection remain the original arithmetic's responsibility.

Each patch retains a 256-word arena for worst-case fallback. Sixteen arenas plus two guards still occupy 32,784 bytes. One new 290-word Int32 metadata buffer adds 1,160 bytes. Each patch's metadata is mode, payload word count and sixteen mask starts (72 bytes). A normal four-point table transports 640 payload bytes plus72 metadata bytes, versus2,048 original payload bytes; dense fallback transports2,048+72 bytes. Thus normal payload decreases while fixed allocation increases by1,160 bytes. No allocator or shared-memory savings are claimed. Shared allocation remains4,176 bytes.

Encoding is inside the constraint-pack kernel. The cooperative reader decodes into the existing shared slots113..368 after the unchanged positive-zero initialization; the zero-friction reader decodes into its original local array. Evaluation functions are unchanged. Decode/encoding costs belong in measured packing/velocity time. Stale arena tails are ignored in compact mode; all eighteen metadata words are written per used patch. Inactive patches are unread, and rejected summaries return before decoding. Stream and barriers retain the original lifetime boundaries.

Actual codec proof covers counts0..4/allmasks, rank deficiency, invalid/nonfinite Gram and controller inputs, signed zero, quiet/signaling NaN payloads, unequal mirrored active bits, local/shared reconstruction, adjacent poison, guards and scratch reuse. Controller and full source/package qualification require exact numeric/work equality before timing. Details and the bounded result are under `build/physics-packed-operators/`; no automatic dispatch/default replacement or combination with cache/warm/TGS is introduced.
